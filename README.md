# Praticar

Repositorio para exercicios, estudos e pequenos projetos.

## Estrutura

- `exercicios/`: exercicios separados por linguagem.
  - `c/`: estudos e testes em C.
  - `csharp/`: projetos de console em C# incluidos na solution.
  - `html/`: testes basicos de HTML.
  - `python/`: exercicios em Python.
- `vibecode/`: projetos e experimentos maiores, mantido sem reorganizacao.
- `Praticar.sln`: solution do Visual Studio para os projetos C#.

## Observacoes

Arquivos gerados por build, como `bin/` e `obj/`, ficam ignorados pelo Git para manter o repositorio mais limpo.
